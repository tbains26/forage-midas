# Midas
Project repo for the JPMC Advanced Software Engineering Forage program

<img width="830" height="598" alt="image" src="https://github.com/user-attachments/assets/5bb8017c-707d-4065-9877-f7e84964a6d8" />

Over the course of this program, I contributed to the design and development of Midas Core, a Spring Boot–based financial services application. I worked on building out a resilient backend architecture by integrating Kafka as a message queue for decoupled, asynchronous communication, and connected the system to an H2 database using JPA to validate and persist transactions with proper balance updates. I extended the platform further by incorporating an external Incentive API, seamlessly posting transactions and applying returned incentive amounts to user accounts. To make the system accessible, I implemented a REST API that exposes account balances through a lightweight, production-ready endpoint. This experience allowed me to apply industry-standard tools and practices—covering event-driven design, database integration, and API development—while strengthening my ability to build scalable, enterprise-grade applications.
